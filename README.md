## ✨ Features
- **Cover Lookup:** Automatically fetch and display book covers.
- **Progress Tracking:** Log pages read and track your reading journey.
- **Search:** Quickly find books in your collection by title or author.
- **Backup:** Secure your library data.

## 🛠️ Tech Stack
- **Language:** Java
- **Database:** Room (SQLite)
- **UI:** Material Design 3 / XML
- **Architecture:** DAO / Local Storage

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/ajmalaman/PersonalLibrary.git`
2. Open the project in **Android Studio**.
3. Let Gradle sync and build the project.
4. Run the app on an emulator or physical Android device.
